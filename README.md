# Yardstick

Yardstick is an interactive demonstration of sports-inspired visualizations for comparing WGU courses, colleges, and university-level results with peer institutions using semantic differential ratings.

## Demo purpose

This repository is intended for demonstration, design review, and prototype development only. It is not a production reporting system.

## Data statement

This repository contains no sensitive, confidential, student-level, or personally identifiable information. Any values displayed are mock, aggregated, de-identified, or otherwise approved for demonstration purposes. They should not be interpreted as official institutional findings.

## Project status

This project is under active development. Visualizations, labels, calculations, and functionality may change.

## Contents

- University-level comparison
- College-level comparisons
- Individual course matchups
- Supporting styles, scripts, images, and demonstration data

## Access and use

Internal WGU demonstration project. Repository contents should not be shared or redistributed without authorization.
